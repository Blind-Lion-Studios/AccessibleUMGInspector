# NVDA User Guide for Accessible UMG Inspector

## Introduction
Accessible UMG Inspector generates plain-text reports specifically formatted for efficient navigation with screen readers, particularly NVDA (NonVisual Desktop Access).

Every operation supports `Format="NvdaText"` or `Format="Both"`. When using NVDA, plain-text output avoids deeply nested JSON syntax, replacing it with clear hierarchical outlines, numbered sections, and standard Markdown headings.

---

## Output Organization

### 1. Serialized Inspection Output
Generated by `InspectSerializedWidgetBlueprint`:
- **Header**: Asset path, root widget class, total widget count, clean package status.
- **Hierarchical Outline**: Indented tree of widgets using numbering (e.g. `1.1`, `1.2`).
  - Each item announces: `WidgetName (WidgetClass) [Visibility] [Focusable] [Enabled]`.
  - Accessible name and summary appear on the next line when authored.
  - Slot alignment and navigation rules appear indented under the control.
- **Warnings Section**: Lists duplicate widget names or missing action bindings.
- **Package Status Verification**: Confirms package was clean before and remains clean after.

### 2. Runtime Inspection Output
Generated by `InspectRuntimeUserWidget`:
- **Header**: Target world, root user widget name, active control count, suppressed control count.
- **Focus Summary**: Identifies which control currently holds passive Slate keyboard focus.
- **Active Screen Controls**: Enumerates only effectively visible, interactable controls on the current screen.
  - Announces: `WidgetName (WidgetClass) [Focusable] [Focused] Bounds: (X, Y, W, H)`.
- **Inactive / Suppressed Controls**: Enumerates collapsed or hidden containers and their children, clearly marked with: `[Suppressed by: <AncestorName>]`.

### 3. Differential Comparison Output
Generated by `CompareSerializedAndRuntime`:
- **Header**: Asset pairing, classification breakdown counts (`Matched`, `Ambiguous`, `SerializedOnly`, `RuntimeOnly`).
- **Priority-Triage Sections**:
  - `Ambiguous`: Highlighted first for human review.
  - `Matched`: Exact 1-to-1 correspondences with discrepancies highlighted.
  - `SerializedOnly`: Blueprint controls not constructed at runtime.
  - `RuntimeOnly`: Dynamic controls created exclusively in code or Slate.
- **Discrepancy Callouts**: Lists parent mismatches, child order shifts, or unexpected state divergences.

### 4. Accessibility Audit Output
Generated by `AuditWidgetAccessibility`:
- **Header**: Target asset, runtime identity, evidence mode (`Serialized`, `Runtime`, `Differential`), total error count, total warning count.
- **Errors Section**: Critical accessibility barriers. Each finding includes:
  - `Rule ID & Name`
  - `Affected Control`
  - `Observed Evidence` (Direct vs Derived)
  - `Why It Matters`
  - `Remediation Guidance`
  - `Limitations`
- **Warnings Section**: Structural or layout risks requiring technical attention.
- **Human Review Required**: Explicit callouts where automated logic cannot determine intent.
- **Not Evaluated**: Rules where required evidence was unavailable in the current inspection mode.
- **Passed Rules**: Authoritative list of rules evaluated with zero defects.
- **Architectural Limitations**: Explicit boundaries and non-claims.

## Recommended NVDA Navigation Strategies

### Heading Navigation (Key: `H` and `Shift + H`)
All reports use Markdown Level 2 (`##`) and Level 3 (`###`) headings:
- Press `H` to jump immediately to the next section:
  - `## ERRORS (Count: N)`
  - `## WARNINGS (Count: N)`
  - `## HUMAN REVIEW REQUIRED`
  - `## PASSED RULES`
- Press `Shift + H` to jump back to previous headings.

### List Navigation (Key: `I` and `Shift + I`)
Audit findings and widget items are formatted as Markdown list items:
- Press `I` to jump from finding to finding or control to control.
- Press `Shift + I` to navigate backwards through items.

### Reading Line by Line (Key: `Down Arrow` / `Up Arrow`)
Once at a finding heading:
- Use standard line reading to read the observed evidence, remediation guidance, and limitations.

### Searching Text (Key: `NVDA + Ctrl + F`)
- Search for `[Focused]` to find the currently active focus target.
- Search for `[Suppressed by` to jump straight to collapsed subtrees.
- Search for `Direct` to locate findings grounded in unambiguous engine reflection.

## Human Review Responsibilities
Accessible UMG Inspector automates structural and property verification, but it cannot replace human review:
1. **Screen-Reader Reading Order**: Verify that arrow keys and Tab navigate logically across controls.
2. **Accessible Name Meaningfulness**: Automated rules verify that a label exists, but human judgment must verify that the label accurately conveys the button's action.
3. **Sound and Speech Feedback**: Confirm that UI sound effects or TTS announcements trigger when controls are activated.
4. **Physical Controller Navigation**: Test game shell screens with Xbox/PlayStation controllers and D-pads.
